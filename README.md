☁️ CrewAI Cloud Agent Studio
A lightweight Streamlit web application for building and running multi-agent research workflows powered by CrewAI and OpenRouter.

🚀 Features
Multi-Model Support: Easily switch between top cloud models (Anthropic Claude 3.5 Sonnet, DeepSeek Chat, Llama 3.3, Gemini, etc.) via OpenRouter.

Interactive UI: Built with Streamlit for fast, browser-based input and visual task tracking.

OpenAI-Compatible Bridge: Fixed custom LiteLLM routing using custom_openai=True to prevent 404 endpoint errors across all OpenRouter models.

Built-in Limits: Configured with max iteration and execution safeguards to optimize API costs and execution speed.

🛠️ Requirements
Python: 3.10 or higher
